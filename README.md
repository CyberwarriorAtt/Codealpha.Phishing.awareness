# Task 2: Phishing Awareness Training

A single-file interactive web module (`index.html`, no dependencies).

## Contents
1. What phishing and social engineering are
2. "Spot the red flags" interactive fake email
3. Link analyzer (detects lookalike domains, IP hosts, HTTP, extra subdomains)
4. Recognising fake websites
5. Best practices and what to do if you clicked
6. Real-world examples
7. Six-question quiz with instant feedback and score

## Run
Open `index.html` in any browser, or enable **Settings → Pages** on GitHub (branch `main`, folder `/`) and use the published link.
